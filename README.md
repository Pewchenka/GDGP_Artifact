# GDGP_Artifact

Unity project using Unity Editor **6000.6.3f1**.

## Open the project

1. Install Unity 6000.6.3f1 through Unity Hub.
2. In Unity Hub, choose **Add project from disk** and select this folder.
3. Open the project and allow Unity to restore packages and import assets.

The repository includes Assets, Packages, and ProjectSettings. Unity caches, logs, generated IDE files, and local user settings are excluded.
